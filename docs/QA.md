# Проверка Native 0.1 — 27 октября 2026

Все данные при проверке синтетические. Ни реальные детские анкеты, ни документы заказчика в репозитории не хранятся.

## macOS Apple Silicon

- Release-сборка C++17, статический wxWidgets 3.3.4, встроенный SQLite 3.54.1 и Inter.
- Проверки ядра CTest: расчёты, пропуски, изоляция классов/дат, отдельные вопросы и взаимные пары, недопустимые выборы, границы шкал, переполнение чисел, календарные даты, CSV-формулы, сохранение/копия/повторное открытие SQLite, PDF.
- GUI smoke-тест прошёл: настоящее окно и пять страниц инициализированы, PDF, CSV и копия созданы, приложение завершилось автоматически.
- PDF: две страницы A4, проверены визуально после рендеринга Poppler. Кириллица и таблицы читаются, на второй странице повторяется заголовок таблицы. Шрифт включён в PDF.
- Проверка совместимости: копия настоящей синтетической базы Electron 0.2 успешно открыта, все 88 ответов на 48 учеников и два обследования прошли валидацию.
- Посторонний SQLite-файл отклоняется до изменения схемы. Создание базы/копии не заменяет существующий файл.
- `otool -L`: только системные библиотеки и Apple frameworks; нет Homebrew/wxWidgets/SQLite dylib.
- Визуальный осмотр самого окна временно не выполнен: Mac заблокирован. Автоматический GUI smoke-тест от блокировки не зависит.

## Windows x64

Первая Windows-сборка в GitHub Actions прошла компиляцию, CTest, запуск настоящего GUI-окна с созданием PDF/CSV/копии и проверку зависимостей EXE. wxWidgets, SQLite, MSVCP и VCRUNTIME DLL рядом с программой не требуются. Результаты доступны в артефактах CI.

GitHub Actions использует Windows Server. Нативного пользовательского тестирования на Windows 11 пока не было. Внешний вид элементов может отличаться от macOS. Сертификата Authenticode нет.

## Методические ограничения

Шкала 1–5 демонстрационная, нормативные ключи не предоставлены. Приложение выполняет описательные расчёты; валидация программы не является валидацией психологической методики. Подробные границы версии перечислены в README.
