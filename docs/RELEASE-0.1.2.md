Оформление ближе к исходной Electron-версии: Inter, синие основные и белые дополнительные кнопки, скруглённые карточки и панели с мягкой тенью, сглаженные графики. Подсветка меню при наведении, состояния кнопок при наведении, нажатии, фокусе и отключении.

Кнопки сохраняют нативную доступность и клавиатурное управление. Выпадающие списки и календарь остаются системными.

Windows: распакуйте ZIP и запустите SchoolMonitor.exe. Дополнительные DLL и фреймворки не нужны. Mac: Apple Silicon, macOS 26+.

Проверены CTest, GUI smoke с PDF/CSV/SQLite, внешний вид и отмена диалогов на Mac. Windows проверяется в GitHub Actions (Windows Server); отдельный ручной тест на Windows 11 не выполнялся.
